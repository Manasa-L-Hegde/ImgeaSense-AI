# ImageSense AI — Mini Project Guide

## Problem statement

Generate a short natural-language description for an input image. The project combines computer vision with sequence generation, showing how visual information can guide a language model.

## Objectives

1. Extract meaningful image features using a pretrained CNN.
2. Generate a caption one word at a time with an LSTM decoder.
3. Build a simple local web interface for caption generation.
4. Evaluate captions on a held-out test split using BLEU and qualitative examples.

## Architecture

```text
Image → MobileNetV2 CNN → 49 spatial visual regions → Attention LSTM decoder → Caption
```

- **Encoder:** MobileNetV2 pretrained on ImageNet, used as a frozen feature extractor. Its final 7×7 feature map provides 49 visual regions.
- **Decoder:** word embedding + LSTM with additive visual attention. At each next-word prediction, the decoder weighs the regions that are most relevant to the caption prefix.
- **Training:** teacher forcing learns the next word from a caption prefix.
- **Split:** 80% train, 10% validation, 10% test by image, avoiding caption leakage.

## Demonstration flow

1. Open the Streamlit app.
2. Upload an image, take a camera photo, or select the included sample.
3. Show the image insights and generate a caption.
4. Explain that every caption is generated by the trained CNN + attention LSTM model.
5. Download the caption report.

## Evaluation after training

Run a quick evaluation first:

```powershell
python -m src.evaluate --data-dir data --limit 25
```

Then run the full held-out test evaluation:

```powershell
python -m src.evaluate --data-dir data
```

The result is saved to `artifacts/evaluation.json`. Report BLEU-1, BLEU-4, and 3–5 generated-caption examples. BLEU measures word overlap, so also discuss whether captions identify the correct objects and actions.

## Limitations and future work

- Flickr8k captions are short and may not describe every object.
- The LSTM can repeat words or miss actions.
- Future work: attention over image regions, beam-search decoding, larger datasets, and transformer-based caption decoders.
